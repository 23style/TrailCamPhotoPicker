# フィールドカメラ写真整理アプリ

フィールドカメラ（トレイルカメラ）で撮影した大量の写真を、撮影日ごとにグループ化して一覧表示し、
残す写真にチェックを入れて、不要な写真をまとめて `delete` フォルダへ移動するためのローカルWebアプリです。

## 特徴

- 撮影日（Exif優先、なければファイル更新日時）ごとに写真をグループ表示
- 残したい写真にチェック、チェックの入っていない写真は「実行」で `delete` フォルダへ一括移動
- 1日1枚しかない写真は初回デフォルトでチェックON（うっかり消さないための安全策）
- サムネイルをクリックして拡大表示、`<` `>` ボタンや矢印キーで前後の写真に移動
- 拡大表示中に「その日の何枚目/その日の総枚数」を表示
- サムネイルサイズをスライダーで調整（元画像の縦横比を維持）
- 作業中のチェック状態を自動保存・自動復元、最後に開いたフォルダも記憶

## 動作環境

- Python 3.x
- Flask, Pillow（`organizer/requirements.txt` 参照）

## セットアップ

```bash
cd organizer
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 起動方法

```bash
cd organizer
.venv\Scripts\python app.py
```

ブラウザで `http://127.0.0.1:5000` を開き、写真フォルダのパスを入力して読み込みます。

## 注意事項

- Flaskの開発サーバーを使用しているため、ローカルでの個人利用を想定しています。
- 「実行」で行われるのはファイルの**移動**（`delete` フォルダへ）であり、完全な削除ではありません。
