# フィールドカメラ写真整理アプリ 仕様書・使い方

## 概要

フィールドカメラ（トレイルカメラ）で撮影した大量の写真を、撮影日ごとにグループ化して一覧表示し、
残す写真にチェックを入れて、不要な写真をまとめて `delete` フォルダへ移動するためのローカルWebアプリ。

- 開発言語: Python（Flask）
- 実行方法: ローカルでFlask開発サーバーを起動し、ブラウザ（`http://127.0.0.1:5000`）から操作する
- 想定利用者: 自分のPCで動かす単一ユーザー利用（公開サーバーとしての利用は想定していない）

## 動作環境

- Python 3.x（venv運用を推奨）
- 主な依存パッケージ: Flask, Pillow（`requirements.txt` 参照）

## セットアップ

```bash
cd organizer
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 起動方法

```bash
cd organizer
.venv\Scripts\python app.py
```

ブラウザで `http://127.0.0.1:5000` を開く。

## 使い方

1. 画面上部のテキストボックスに写真フォルダのパスを入力し「読み込む」を押す。
   - 前回読み込んだフォルダは自動的に記憶され、次回起動時は自動でそのフォルダが表示される。
2. 写真が撮影日ごとにグループ化されて一覧表示される。
3. 残したい写真にチェックを入れる（チェックのデフォルト状態は下記「チェックのデフォルト仕様」を参照）。
4. サムネイルをクリックすると拡大表示され、`<` `>` ボタン（または矢印キー）で前後の写真に移動できる。
   拡大表示中もチェックのON/OFFが可能。
5. 画面上部のスライダーでサムネイルの表示サイズを調整できる（80〜320px）。
6. 「実行」ボタンを押すと、チェックが入っていない写真がすべて `<フォルダ>/delete/` へ移動される。
   実行前に確認ダイアログが表示される。

## 仕様詳細

### 日付グループ化の基準

写真のExif情報の撮影日時（`DateTimeOriginal`）を優先して使用する。Exif情報が無い、または読み取れない場合は
ファイルの更新日時（mtime）にフォールバックする。

### チェックのデフォルト仕様

- 通常、写真のチェックは**デフォルトでOFF**（残さない）。
- ただし、**その日の写真が1枚しかない場合は、デフォルトでチェックON**にする。
  - この自動ONは、そのフォルダにまだ作業状態の保存ファイル（`.organizer_state.json`）が
    存在しない場合（＝一度もそのフォルダを保存していない、初回読み込み時）にのみ適用される。
  - 一度でも保存が行われたフォルダでは、保存済みのチェック状態が常に優先される。
    そのため、1枚しかない日の写真をユーザーが明示的にチェックOFFにして保存した場合、
    その後ページを再読み込みしてもOFFのまま復元される（自動ONで上書きされない）。

### 作業状態の自動保存・復元

- チェック状態を変更すると、自動的（デバウンス約0.5秒）に写真フォルダ内へ
  `.organizer_state.json` として保存される（内容: チェックが入っている写真ファイル名のリスト）。
- 同じフォルダを再度開くと、保存されている内容が自動的にチェック状態へ反映される。
- 「実行」でファイル移動が完了すると、`.organizer_state.json` は自動的に削除される
  （その回の作業が完了したため）。

### 最後に開いたフォルダの記憶

- 最後に読み込みに成功したフォルダのパスは、アプリ側（`organizer/.last_folder.txt`）に保存される。
- フォルダ未指定でアプリを開くと、自動的にこのフォルダが読み込まれる。

### 実行（削除移動）の動作

- チェックが入っていない写真を `<フォルダ>/delete/` フォルダへ移動する。
  `delete` フォルダが存在しない場合は自動作成する。
- 移動先に同名ファイルが既に存在する場合は、`ファイル名_1.jpg` のように連番を付けて衝突を回避する。
- スキャン対象は指定フォルダ**直下**の画像ファイルのみ（サブフォルダは再帰的に走査しない）。

### サムネイル

- サーバー側で長辺640pxのサムネイルを生成し、`organizer/.thumb_cache/` にキャッシュする
  （元ファイルのパス・更新日時・生成サイズをキーにしたキャッシュのため、元写真が変わると再生成される）。
- 表示は元画像の縦横比を維持する（切り抜きは行わない）。
- 画面上部のスライダーで表示サイズを80〜320pxの範囲で調整できる。

### 拡大表示（ライトボックス）

- サムネイルをクリックすると拡大表示。
- `<` `>` ボタン、または左右矢印キーで前後の写真に移動できる。
- 拡大表示中でもチェックのON/OFFが可能（一覧側の状態と同期する）。
- 移動先の写真が別の日付になる場合、写真を直接切り替える前に日付ラベルを表示する
  ワンクッション画面を挟む。クリックすると実際にその写真へ切り替わる。
- 拡大表示中の写真の上部（画像に重ねない領域）に、日付ラベルと「その日の何枚目/その日の総枚数」
  （例: `3 / 8枚`）を表示する。
- Escキーで閉じる。

## ファイル構成

```
organizer/
  app.py              Flaskアプリ本体
  requirements.txt    依存パッケージ
  templates/
    index.html        一覧・チェック画面
    done.html          実行完了画面
  static/
    style.css
    app.js
  SPEC.md             本ドキュメント
  .venv/              venv（Git管理外）
  .thumb_cache/        サムネイルキャッシュ（Git管理外・自動生成）
  .last_folder.txt     最後に開いたフォルダのパス（Git管理外・自動生成）
```

写真フォルダ側に自動生成されるファイル:

```
<写真フォルダ>/
  .organizer_state.json   作業中のチェック状態（実行完了で自動削除）
  delete/                  実行で移動された写真の格納先
```

## 既知の制約

- Flaskの開発サーバー（`app.run(debug=True)`）を使用しているため、本番運用や複数人同時利用は想定していない。
- 対応画像拡張子: `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`
- サブフォルダは走査しない（指定フォルダ直下のみ）。
